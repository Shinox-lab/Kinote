# Collections and views

<ClipVideo name="collections" label="A collection shown as a table, a board, a calendar and a timeline" />

A **collection** is a page whose sub-pages share a set of fields, like a project list where every project has a
status, an owner and a due date. A **view** shows those sub-pages as a table, a board, a calendar or a timeline.

## Make a collection

1. Open the page that will hold the items, for example *Roadmap*.
2. Click **Page actions** and choose **Turn into collection**.
3. Click **+ Add a field**, give it a name, pick a type, and click **Add**. Repeat for each field.

Field types: **Text**, **Number**, **Date**, **Select**, **Multi-select**, **Person**, **Checkbox** and **Page**. For
**Select** and **Multi-select**, type the choices you want.

Every sub-page of the collection now has these fields at the top. Fill them in there, or in a view. Field values are
searchable like the rest of the page.

## Add a view

1. On an empty line, type `/collection view` and choose **Collection view**.
2. The view starts as a **Table**. Use **Add a view** to add a **Board**, a **Calendar** or a **Timeline** tab.

You can put a view on the collection's own page or on any other page.

- **Table**: one row per page. Edit any cell in place. **+ New** adds a page.
- **Board**: columns by a Select field, such as Status. Drag a card to another column to change it.
- **Calendar**: pages on their date. Drag one to another day to change the date.
- **Timeline**: bars from a start date to an end date.

**Filter** shows only the pages that match. **View** lets you rename the view and change how it's set up.

Changes to a view are saved for everyone. If you can only read the page, you can still change a view for yourself, but
it isn't saved.
