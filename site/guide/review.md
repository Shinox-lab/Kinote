# Review and page status

<ClipVideo name="review" label="A change waits for approval, a reviewer approves it, and the page is indexed" />

Some spaces hold things that need a second pair of eyes, like client details or policies. Turn on **review** for a
space and every change to its pages waits for a reviewer before search and Ask use it. You keep editing as normal; the
review is about which version counts.

## Saving and indexing

Kinote saves as you type. A page is **indexed** when a version of it is stored and made searchable. That happens:

- by itself, a couple of minutes after people stop editing the page, or
- straight away, when you open the status chip under the title and click **Index now**.

In a space with review on, the button reads **Submit for review** instead, and the version waits for a reviewer.

## What each status means

The chip under a page's title always shows one status.

| Status | What it means |
|---|---|
| **Indexed · v7** | Version 7 is the current one, and search and Ask use it. The time beside it says when. |
| **3 unindexed changes** | You or others changed the page since it was last indexed. Those changes aren't searchable yet. |
| **Saved · indexing soon** | Saved. It will be indexed by itself shortly. |
| **Indexing…** | Kinote is indexing it right now. |
| **Saved · not indexed (awaiting approval)** | The space needs review, and this version is waiting for a reviewer. |
| **Saved · changed since v3, awaiting approval** | Version 3 is waiting for a reviewer, and the page has changed again since. |
| **Not indexed · v3 rejected** | A reviewer rejected version 3. The last approved version, if any, still counts. |
| **Index failed** | Indexing went wrong. Click **Retry**. |
| **Withdrawn** | A reviewer took this page out of search. |

Files have a few of their own: **Reading text…** while Kinote reads the text out of the file, **Stored · no searchable
text** for a file with no text in it, and **Extraction failed** when the file couldn't be read.

## Reviewing a change

If you're a reviewer in a space, changes waiting for you show under **Reviews** in the sidebar, with a count.

1. Click **Reviews** and choose an item.
2. Read it. **Full document** shows the whole page; **Changes only** shows just what changed.
3. Click **Approve** to make it the current version, or **Reject…** and write a short note saying why.

You can't approve a change you made yourself. Someone else has to.

Changes made by AI agents follow the same rule as people's: in a space with review on, they wait for a reviewer too.

## Restoring an older version

1. Open the status chip and choose **History**.
2. Find the version you want and click **Restore**.
3. Confirm with **Restore version 4** (or whichever number).

Restoring puts that version's content back on the page as a new version. Older versions are kept, so nothing is lost.
