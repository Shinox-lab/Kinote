# Roadmap

Kinote's core is built and in use: capture and routing, live co-editing, review, files and search, Ask, collections,
drawings, links and comments. These are what's being worked on next. There are no dates; each ships when it's ready.

- **WhatsApp groups as a source** (In development). File what your team says in a group chat the same way you file a
  note.
- **Google Drive sync** (In development). Keep a Drive folder in step with a space, so its files are previewed and
  searchable.
- **MCP for external AI agents** (In development). Let the AI agents you already use read and write your wiki, with the
  same permissions and review rules as people.
- **Self-maintaining wiki** (In development). Kinote follows the sources a page was built from, updates it when they
  change, and flags broken links and contradictions.
- **Space export** (In development). Download a whole space as Markdown files.

Want to help with one of these? See [Contributing](./contributing/).
